# 管理台设计规范

采用 React + TypeScript + Ant Design。组件库约束控件、状态和视觉规则，业务页面按实际操作流程组合，不套用固定后台模板。

## 页面结构

| 区域 | 页面与交互 |
|---|---|
| 服务概览 | 关键指标、工作区入口、连接地址、最近活动 |
| 知识工作区 | 知识库、增量收件箱、模板 |
| 服务管理 | Git 仓库、Agent 与密钥、访问活动 |

知识库用表格展示资源，详情抽屉统一承载文件浏览、模板与工作范围、基本设置。收件箱用列表与详情分栏，正文、领取状态及处理结果放在同一上下文。短表单使用弹窗，复杂详情使用抽屉。

## 视觉与组件

- `frontend/src/theme.ts` 是统一主题入口：青绿色主色、浅灰页面背景、白色内容区，正文 14px、控件 36px、圆角 8px。状态色采用 Ant Design 语义 token，明确设置浅色背景、边框和深色文字，避免低明度主色自动生成过暗底色。
- 表单、表格、菜单、按钮、选择器、弹窗、抽屉和反馈使用 Ant Design；目录选择、文件预览、模板绑定等组合成可复用业务组件。
- CSS 负责布局，颜色通过主题变量引用。新增页面不自行定义另一套按钮或输入框。
- 页面标题配主要操作，下方直接进入任务内容。只保留帮助用户决策的说明，不增加装饰小字、口号或无实际意义的状态标签。
- 表格操作区保持一行，常用操作直接展示，其余放入“更多”菜单；Git 仓库保留“更新”，关联、设置和记录放入菜单。
- 窄屏收起导航，收件箱上下排列，宽表格在自身区域横向滚动。

## 行为约束

- 目录单击选中、双击进入；保留“打开”、上一级和路径面包屑。
- 读取提供加载、空白、错误及重试状态；提交防止重复点击，失败保留输入。
- 撤销 Key、停用知识库及解除绑定要求确认；后端拒绝时显示实际错误。
- 管理员令牌、临时领取凭证只保存在页面内存。退出中止请求；过期响应不能恢复会话。Key 完整值只在创建后弹窗展示，弹窗内可重复复制。
- “权限设置”按知识库在同一窗口配置访问与提交权限，一次保存同时生效。取消访问同时取消提交；提交权限不代表正式知识文件写权限。
- 材料、路径和文档均按纯文本渲染。动态样式使用每次 HTML 响应生成的 CSP nonce，脚本仍限同源。
- 模板安装、绑定与处理结果回填不代表程序已运行或知识已发布；页面只展示已实现能力。

## 开发与验证

```bash
cd frontend
npm ci
npm test
npm run build
```

构建产物自动安装至 `folder_kb/web`，先复制带哈希的资源再替换入口；保留旧哈希资源，避免已打开页面丢失依赖。产物不提交 Git。Docker 和 CI 自动构建；源码运行及 Python 打包前须先构建前端。

`npm run dev` 启动 Vite，管理 API 默认代理到 `127.0.0.1:8791`。开发代理仅用于本机。浏览器验证可通过 `python -m tests.admin_ui_fixture` 创建独立知识目录、状态库和模板上传文件。
