# 管理台设计规范

采用 React + TypeScript + Ant Design。组件库约束控件、状态和视觉规则，业务页面按实际操作流程组合，不套用固定后台模板。

## 页面结构

| 区域 | 页面与交互 |
|---|---|
| 服务概览 | 关键指标、工作区入口、连接地址、最近活动 |
| 知识工作区 | 知识库、增量收件箱、插件 |
| 服务管理 | Git 仓库、Agent 与密钥、访问活动 |

知识库用表格展示资源，详情抽屉统一承载文件浏览、插件与工作范围、基本设置。收件箱用列表与详情分栏，正文、领取状态及处理结果放在同一上下文。短表单使用弹窗，复杂详情使用抽屉。

## 视觉与组件

- `frontend/src/theme.ts` 是统一主题入口：青绿色主色、浅灰页面背景、白色内容区，正文 14px、控件 36px、圆角 8px。状态色采用 Ant Design 语义 token，明确设置浅色背景、边框和深色文字，避免低明度主色自动生成过暗底色。
- 表单、表格、菜单、按钮、选择器、弹窗、抽屉和反馈使用 Ant Design；目录选择、文件预览、模板绑定等组合成可复用业务组件。
- CSS 负责布局，颜色通过主题变量引用。新增页面不自行定义另一套按钮或输入框。
- 页面标题配主要操作，下方直接进入任务内容。只保留帮助用户决策的说明，不增加装饰小字、口号或无实际意义的状态标签。
- 表格操作区保持一行，常用操作直接展示，其余放入“更多”菜单；Git 仓库保留“更新”，关联、设置和记录放入菜单。
- 窄屏收起导航，收件箱上下排列，宽表格在自身区域横向滚动。

## 行为约束

- 目录单击选中、双击进入；保留“打开”、上一级和路径面包屑。
- 读取提供加载、空白、错误及重试状态；提交防止重复点击，失败保留输入。
- 撤销 Key、停用知识库及解除绑定要求确认；后端拒绝时显示实际错误。
- 管理员令牌、临时领取凭证只保存在页面内存。退出中止请求；过期响应不能恢复会话。Key 完整值只在创建后弹窗展示，弹窗内可重复复制。
- “权限设置”按知识库配置读取、Grep、Search 和只读/提交收件箱/直接写入，一次保存同时生效，并支持 Key instructions。取消读取同时清除其他能力。直接写入需库管理者在「Agent 接入」显式开启，提交收件箱不等于直接发布。表格只有条目较多时才显示内部纵向滚动条。
- 材料与路径按纯文本渲染。用户工作区使用 react-markdown + remark-gfm 展示 Markdown，禁用原始 HTML 和图片加载，仅开放 HTTP(S) 外链；编辑使用 Milkdown / Crepe，直接编辑渲染后的正文并存回 Markdown；保留源码模式。元数据、HTML、图片、脚注和特殊链接等不支持的格式自动使用源码，正文往返语义检查不通过也回退；初始化不改写原文。代码编辑器使用同一 CSP nonce。动态样式使用每次 HTML 响应生成的 CSP nonce，脚本仍限同源。
- 模板安装、绑定与处理结果回填不代表程序已运行或知识已发布；页面只展示已实现能力。

## 开发与验证

```bash
cd frontend
npm ci
npm test
npm run build
```

构建产物自动安装至 `folder_kb/web`，先复制带哈希的资源再替换入口；保留旧哈希资源，避免已打开页面丢失依赖。产物不提交 Git。Docker 和 CI 自动构建；源码运行及 Python 打包前须先构建前端。

`npm run dev` 启动 Vite，管理 API 默认代理到 `127.0.0.1:8791`。开发代理仅用于本机。浏览器验证可通过 `python -m tests.admin_ui_fixture` 创建独立知识目录、状态库和模板上传文件。

用户工作区顶层知识库与内部目录共用紧凑文件列表（名称、修改日期、类型、大小）。单击选择、双击或 Enter 打开，面包屑与上一级导航；有编辑权限的文档打开即可原位编辑，无需切换编辑状态；只读用户仍只显示正文。阅读与编辑共用字体、行距和正文宽度，使用原生光标。修改显式保存为草稿，审核后发布；离开未保存内容仍需确认。单页列表不显示分页器；目录分页追加加载。

人用工作区采用单行顶部栏：面包屑、当前视图菜单与主要操作集中展示，取消重复大标题和独立标签栏。侧栏支持收起为图标；文档为无外框正文画布，正文/源码切换放入顶部栏。目录行内提供“打开”，不额外占据底部一行。

正文编辑顶部提供段落格式菜单，可将当前段落转换为正文、H1–H6、列表、引用和代码块。菜单项目与顺序由 `frontend/src/blockFormats.ts` 配置，不添加不能往返保存到 Markdown 的格式。转换保留选区，支持撤销；源码模式不显示该菜单。

工作区外层不滚动，侧栏固定，右侧内容独立滚动。个人 Key 页面默认只显示列表，“添加 Key”弹窗填写并创建，成功后独立显示复制窗口；失败留在表单中。源码输入框使用固定初始行数和内部滚动，不使用会向 body 插入测量控件的 autoSize。

段落左侧六点手柄支持单击打开该段落格式菜单，拖动仍用于排序；支持键盘 Enter/空格打开菜单，滚动或 Escape 关闭。

角色、组织和筛选选择器按用途设置稳定宽度，不随当前选项文字变化；文档格式与视图按钮预留最长标签的空间。行内表单允许换行，窄屏筛选器占满可用宽度；短枚举选项完整显示。

组织管理仅保留“成员与部门 / 用户组”一层标签。部门树作为成员筛选导航，列表直接显示部门、用户组和组织角色；添加用弹窗，成员资料用侧栏。组织切换和创建使用紧凑工具栏，不常驻表单。组织管理页面内，部门树与成员列表各自滚动。

管理台的账号管理、组织管理、知识库归属为独立侧栏页面。组织管理不套卡片、不重复显示大标题，不提供用户工作区跳转；顶部直接放组织选择与操作，主体铺满剩余空间。
