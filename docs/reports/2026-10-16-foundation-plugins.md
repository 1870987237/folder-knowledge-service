# 基础插件首版

## 交付

- `bm25-markdown@1.0.0`：明确命名为 BM25 Markdown 检索，包含章节分块、中文双字/英文词分词、SQLite FTS5/BM25、目录过滤和原文行号。不含向量检索或回答生成。
- `general-knowledge@1.0.0`：可初始化的通用 Markdown 模板，按指南、概念、参考、决策组织；自带增量更新和相同 BM25 程序，适配一个库绑定一个插件的现有机制。
- 源码在 `examples/plugins/`，独立标准库程序包，不修改平台的更新/检索协议。两个 ZIP 与 `plugin.json` 已生成在 `dist/<id>-1.0.0/`，并通过本地 8791 管理 API 注册安装。

旧 `simple-rag` / `simple-rag-python` 的安装版本、定义及历史评测证据保留；已有绑定不自动迁移。新库选明确命名的基础插件。旧绑定如需迁移，应显式选择新插件并重建索引，不能原地改写不可变版本。

## 通用知识更新

用户确认：精确去重＋模型语义合并建议；Markdown 文档＋目录索引；候选人工审核后发布。

相同材料 ID 重放复用结果；ID 改载荷拒绝处理。对同标题、上下文、范围及正文的新内容自动去重并保留来源，相关文档改变后不复用过期去重记录。模型提出新增、补充合并、语义重复、纠错或待审决策，程序校验结构、目标、范围和原文证据。观察和模型识别的冲突进入 metadata 待审区，不直接成为可检索知识。候选需审核，发布不自动建索引。

原始输入快照保持不变，辅助文件保留。元数据保存来源、处理决定、旧内容及文件哈希。直接编辑托管 Markdown 后，更新器拒绝覆盖并要求显式迁移，这是首版限制；不声称已支持任意现有库的无缝导入或网页修改后的自动协调。
