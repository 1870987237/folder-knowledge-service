# README 视觉资源

本目录与 `folder-kb-memory-template` 使用同一视觉约定：青绿色标志、浅色结构图、轴向连线和文件夹图标。

- `brand.svg`：透明背景的项目标志；由 README 的 `img` 控制显示宽度。
- `overview.svg`：1100 × 470 的服务接入示意图；作为普通图片嵌入，不依赖脚本或远程资源。

正文保持 Markdown，居中标题、导航及图片采用 GitHub 支持的基础 HTML。SVG 内的文字和图形可直接修改；使用系统字体，含中文字体回退。重要信息同时在正文和图片替代文字中提供。

颜色：标志 `#0f766e`，远程分支 `#0d9488`，背景 `#f8fafc`，节点 `#ffffff`，正文 `#334155`。更新插图时同步维护正文中的实际功能边界。
